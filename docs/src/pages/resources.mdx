# Resources

This page contains a list of resources that may be helpful to you when writing
Assurance Plugins and using this repository

## React Spectrum

Assurance plugins are styled using Adobe's
[React Spectrum](https://react-spectrum.adobe.com/react-spectrum/), which offers
many components you can utilize to build your own components and plugins.

## Toolkit

[Griffon Toolkit](https://opensource.adobe.com/griffon-toolkit/) is a simple
library to help Assurance Plugin Developers build plugins. Plugins can be
enabled by Adobe customers to add additional features to the Assurance UI. It
hosts schemas of each event type that can be emitted during an Assurance
session, and utility functions for matching and interacting with them.

## Validation Plugins

[Validation Plugins](https://github.com/adobe/griffon-validation-plugins) is a
repository that holds all of the validation plugins run by Assurance. If you
would like to create a new validator for your given use case, this is the
project to add it in.
